# 体素山谷 · Voxel Valley

2048 × 2048 方块的无缝大陆，第一人称自由探索。地形、草海、云层、水面与音效**全部程序化生成**，没有任何美术资源。

Vite 7 + React 19 + TypeScript + Three.js(0.186) + Tailwind 4。

## 运行

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # 产出单文件 dist/index.html（vite-plugin-singlefile）
npm test           # 节点侧自测：转向逻辑 + 地形/区块管线
```

### 视角控制：两种模式

1. **指针锁定（默认）** —— 点击「进入世界」后浏览器锁定鼠标，直接移动鼠标转视角。
2. **按住拖动（回退模式）** —— 当浏览器拒绝指针锁定时自动启用：**按住鼠标左键拖动**转视角，`Esc` 退出。

   > 拒绝锁定很常见：页面被嵌在 iframe（在线预览、代码沙箱、文档站点）且没有 `allow="pointer-lock"`、
   > 用户手势已被消耗、权限被拒、或浏览器未实现该 API。
   > 早期版本把这些失败**全部静默吞掉**，于是「进入世界」按钮看上去是坏的 —— 点了没反应。
   > 现在 `src/world/steering.ts` 统一处理：拿不到锁定就一定回退到拖动模式（最长 400ms 内必答），
   > 游戏永远进得去；HUD 会提示当前处于哪种模式。

## 结构

```
src/
├─ App.tsx                 状态中枢：引擎生命周期 → UI（进度 / 就绪 / 统计 / 小地图 / 指针锁）
├─ ui/
│  ├─ StartScreen.tsx      加载页：进度条、四档画质、进入世界、错误提示
│  └─ HUD.tsx              准星、坐标/海拔/地貌/时间/速度、FPS、小地图、操作提示
└─ world/
   ├─ Engine.ts            渲染器、光照与昼夜、区块流式加载、玩家物理、统计回传
   ├─ worldgen.ts          世界常量与地形公式（域扭曲 → 大陆 → 河谷盆地 → 山脊 → 河流 → 海滩 → 海岸线）
   ├─ noise.ts             零依赖 simplex 噪声 + fbm / ridged / hash
   ├─ chunkWorker.ts       Worker：区块网格（表面剔除 + 烘焙 AO）与 1024² 高度图
   ├─ shaders.ts           天空 / 水面 / 草 / 云的 GLSL
   ├─ steering.ts          指针锁定与拖动回退（可单测）

tests/
├─ steering.test.ts        用假 DOM 覆盖 9 条锁定/回退路径
└─ world.test.ts           地形高度分布、高度图耗时、Worker 区块几何
```

## 实现要点

- **流式世界**：按玩家所在区块半径（视距 / 32）增量构建，按距离排序入队，超出半径卸载，仅近处区块投射阴影。
- **只画表面**：区块网格只生成顶面 + 侧面裙边，并烘焙四角环境光遮蔽，按 AO 梯度翻转三角剖分避免对角线瑕疵。
- **高度图复用**：1024² 高度场先算一次，供水面深度采样（岸线泡沫/深浅渐变）、出生点选址与小地图使用。
- **空气透视**：地形材质通过 `onBeforeCompile` 改写雾计算，让雾随海拔衰减，远处雪峰保持清晰。
- **画质档位**：同时控制区块半径、草密度与范围、阴影贴图分辨率、pixelRatio。
