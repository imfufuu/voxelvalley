# 体素山谷 · Voxel Valley

9048 × 9048 方块的无缝大陆，第一人称自由探索。地形、山脉、河流、冰川湖、云层、树木与音效**全部程序化生成**，没有任何美术资源。

Vite 7 + React 19 + TypeScript + Three.js(0.186) + Tailwind 4。

## 运行

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # 产出单文件 dist/index.html（vite-plugin-singlefile）
npm test           # 节点侧自测：转向逻辑 + 地形/区块管线
```

### 指令（`/help` 查看全部）

时间系统只是一部分，传送、画质、天气、速度都可以改：

```
/time <0-24>       设置时刻（小时）          /tick <0-24000>   按 tick 设置（一天 24000）
/freeze            暂停时间                  /resume          恢复正常流速
/timescale <倍率>  时间流速倍率（0 = 静止）
/tp <x> <z> [y]    传送（y 省略则落到地表）  /surface         回到当前位置地表
/fly               切换飞行                  /speed <倍率>    行走速度倍率
/quality <档位>    low / medium / high / ultra
/clouds <0-1>      云量                      /fov <度数>      视野角
/where             坐标 / 高度 / 水深 / 时间 /world            世界信息
/menu              退出到开始界面
```

昼夜流速不再有快捷键循环 —— 只有正常速度，`/freeze` 冻结、`/timescale` 调倍率。

### 视角控制：两种模式

1. **指针锁定（默认）** —— 点击「进入世界」后浏览器锁定鼠标，直接移动鼠标转视角。
2. **按住拖动（回退模式）** —— 当浏览器拒绝指针锁定时自动启用：**按住鼠标左键拖动**转视角，`Esc` 退出。

   > 拒绝锁定很常见：页面被嵌在 iframe（在线预览、代码沙箱、文档站点）且没有 `allow="pointer-lock"`、
   > 用户手势已被消耗、权限被拒、或浏览器未实现该 API。
   > 早期版本把这些失败**全部静默吞掉**，于是「进入世界」按钮看上去是坏的 —— 点了没反应。
   > 现在 `src/world/steering.ts` 统一处理：拿不到锁定就一定回退到拖动模式（最长 400ms 内必答），
   > 游戏永远进得去；HUD 会提示当前处于哪种模式。

## 实现要点（本次改造）

- **更真实的山脉**：域扭曲大陆 → 盆地 → 脊状多重分形山脉 → 罕见的**极天山脉**（最高 ~440m）→ 山麓与微地形。约 1% 的地表高于 240m，山峰会**刺穿 168–236m 的云层**。
- **河流与冰川湖**：河流按噪声下切河道并回灌 72% 形成水面；高地按缓慢变化的"地下水位"生成湖泊，高海拔湖泊冻结成冰面。内陆水体由区块生成独立水面网格（带烘焙水深，用于岸线泡沫、深浅渐变与冰面判定），海洋仍用单张大平面。
- **体积云**：不再是方块云。整层云是一个跟随相机的大包围盒，片元着色器在其中光线步进 3D 噪声（含向太阳的透光采样与抖动），云层像被光照亮的雾，山脉可以直接穿过去。步进数与噪声八度随画质档位变化（12–34 步）。
- **景物**：树木（云杉 / 阔叶）与巨石在 Worker 内随区块一次性解析，主线程只做矩阵合成 —— 每次重建从"几万个噪声采样"降到几毫秒。树冠会随风摆动（`onBeforeCompile` 注入顶点位移）。
- **世界尺寸**：2048² → **9048²**（高度图仍是 1024² 采样，约 2s 完成）。
- **涉水音效与脚步频率**：新增 `SoundKit.wade()`（低频推水 + 水滴 + 离水"啪"声，按水深变化）；脚步从每半个摆动周期一次（疾跑约 8 次/秒）降到每 1.5 个周期一次（约 2.6 次/秒）。

## 实现要点（原有）

- **流式世界**：按玩家所在区块半径（视距 / 32）增量构建，按距离排序入队，超出半径卸载，仅近处区块投射阴影。
- **只画表面**：区块网格只生成顶面 + 侧面裙边，并烘焙四角环境光遮蔽，按 AO 梯度翻转三角剖分避免对角线瑕疵。
- **高度图复用**：1024² 高度场先算一次，供水面深度采样（岸线泡沫/深浅渐变）、出生点选址与小地图使用。
- **空气透视**：地形材质通过 `onBeforeCompile` 改写雾计算，让雾随海拔衰减，远处雪峰保持清晰。
- **画质档位**：同时控制区块半径、草密度与范围、阴影贴图分辨率、pixelRatio。
